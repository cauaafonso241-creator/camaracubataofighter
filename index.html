Projeto web estático em HTML, CSS e JavaScript. Retratos e referências locais foram fornecidos para este projeto. Mecânicas, VFX, interface e áudio procedural são originais desta implementação.

Os personagens são avatares ficcionais; golpes e poderes não descrevem fatos sobre as pessoas representadas.

Não utiliza sprites, músicas, efeitos sonoros, logos ou código proprietários de outros jogos.
