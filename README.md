# Câmara Cubatão Fighter

Jogo de luta arcade fictício criado para fins de entretenimento e trabalho acadêmico. Os personagens são representações caricaturais e os golpes/poderes são inteiramente fictícios.

## Rodar
Abra `index.html` com Live Server ou execute `python3 -m http.server 8000` no Codespaces.

## Controles
- Movimento: A/D
- Pulo: W
- Defesa: S
- Soco: J
- Chute: K
- Especial: L
- Pausa: Esc

Projeto em HTML, CSS e JavaScript puro, sem build obrigatório.
